# Generated Rust/Python JSON framing differential (2026-07-31)

## Scope and prior-gap audit

Working base: `c594c290308bf3c0b381a255d75179c7cb177c10`.

The protocol crate already had deterministic generated coverage for arbitrary
JSON values, supported message round-trips, duplicate command composites,
escaped command keys, truncation, and malformed UTF-8. The compatibility crate
already had live Python coverage, but that coverage used fixed hand-written
protocol and session scenarios. No test generated raw framed input and
differentially compared Sorotte with the pinned Syncplay JSON framing
implementation.

This slice fills that gap without replacing an existing test.

## Oracle and boundary

The independent side is Syncplay's actual
`syncplay.protocols.JSONCommandProtocol` loaded from the configured local
oracle checkout. The focused run verified:

- repository: `https://github.com/Syncplay/syncplay.git`
- revision: `d1c5f85af377c960c5a940707c4d01bc84fd9c3f`

The Python probe subclasses that protocol only to record handler dispatches and
error counts. It invokes `lineReceived()` directly with each generated byte
line. Sorotte independently applies its UTF-8 boundary and production
`decode_message_line_items()` codec. Accepted cases compare the exact command
order and parsed payload values; rejected cases must dispatch no partial
commands.

All input and output remain in process-owned stdin/stdout memory. The slice
does not open a socket, contact a remote target, use credentials, write
fixtures, persist generated input, or change the pinned oracle.

## Deterministic campaign

- Seed: `0x5a17d1ffe2c4907b`
- Fixed budget: 256 cases
- Valid cases: 224
- Malformed JSON cases: 16
- Malformed UTF-8 cases: 16
- Supported commands: `Hello`, `Set`, `List`, `State`, `Chat`, `Error`, `TLS`
- Valid generation includes escaped command keys, line-safe surrounding
  whitespace, multi-command objects, and at least 100 duplicate-command cases.
- Duplicate objects exercise Python and Rust's first-position command ordering
  with the last duplicate payload value.
- Malformed UTF-8 covers seven bounded invalid byte classes.

The request and response use closed schemas. The response echoes the seed and
budget, reports `processed = 256`, and must contain every unique case ID
exactly once. The Rust test independently checks the exact 224/32
accepted/rejected partition and the complete seven-command inventory.

The test is a required-live sentinel. Ordinary optional runs may retain the
repository's existing missing-prerequisite behavior, while
`SYNCPLAY_REQUIRE_LIVE_INTEROP=1` prevents the new test from taking that early
return and the required matrix rejects any emitted skip event. The closed
minimum inventory is now 144 tests.

## Defect outcome and limitations

The generated campaign found no Rust/Python parity defect: all 256 cases
matched. Its value is regression detection at a boundary previously covered
only independently or with fixed compatibility inputs.

This is a line-level framing differential, not a network stream segmentation
test. It intentionally excludes non-standard JSON numbers and invalid
top-level protocol shapes, and it does not exercise stateful server behavior;
those concerns remain owned by existing adversarial codec, raw-loopback, and
live session suites.
