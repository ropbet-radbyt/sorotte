# Compose playback-lifecycle assurance across independent proof layers

No single Sorotte test layer is authoritative for the whole playback lifecycle. We will compose an independent state/transition model, exact boundary contracts, and multi-process product walks using the actual server, multiple clients, and real players; production projections and mock-server verticals remain useful evidence but cannot substitute for an independent oracle or a crossed system boundary. This costs more orchestration than one monolithic end-to-end suite, but preserves fast shrinking and causal diagnosis while preventing any one consistently wrong implementation path from proving itself.

GUI and server publication therefore depend on one reusable exact-SHA lifecycle gate. The gate exercises release-mode candidates with the pinned supported player, retains a privacy-safe failure projection, and refuses publication while any declared lifecycle gap remains open.
