## Confirmed failures closed during continuation

The handover's three server findings were reproduced before repair: controlled
room creation bypassed framing admission, small peer-byte limits could accept
undeliverable reliable state, and a queued flush could consume about five seconds
despite a 200 ms shutdown budget. Regression logs preserve the failures and
their corrected behavior, including a full actor queue and held SQLite lock.

The settings mutation survivor was absent-key insertion into a later INI
section. Resource coverage now independently exercises every invalid ceiling,
non-default valid limits, and unchanged reservations at capacity. Equivalent
equal-size resize arithmetic was simplified rather than counted as a killed
mutant. The Windows mutation parser accepts the pinned producer's nonzero
signed 32-bit `Failure` values; zero, booleans, and unknown statuses still fail.

Linux real mpv exposed a separate loading race: `load-script` acknowledged before
the Lua worker opened `/proc/<owner>/fd/<directory>/sorotte_network_options.lua`.
mpv's own log recorded `No such file or directory` after the lease was dropped.
The delayed-open transport regression and real bridge/cache tests pass with the
lease retained through acknowledgement. The bridge fixture now uses null audio
and video outputs and starts paused, so its event ordering does not depend on
audio hardware or a short media file reaching EOF.
