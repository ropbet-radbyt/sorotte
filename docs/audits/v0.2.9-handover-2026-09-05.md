### 2. A02/A10: configured per-peer byte ceiling is absent from admission

`ServerResourceLimits` currently accepts a 1,024-byte per-peer queue budget with the default 64 MiB aggregate budget. Two large-frame peers can then accept a file extension around 2,000 bytes, committing canonical state and producing a reliable frame of 2,089 bytes. The network writer's reservation can never enqueue that frame under the 1,024-byte ceiling, so healthy recipients are overload-closed.

The same local frame harness demonstrates this. Relevant code: [resources.rs](/C:/Users/shaun/Documents/workspace/sorotte/tmp/v0.2.9/crates/sorotte-server/src/resources.rs:19), [network.rs](/C:/Users/shaun/Documents/workspace/sorotte/tmp/v0.2.9/crates/sorotte-server/src/network.rs), and frame projection in `frame_limits.rs`.

Make the configuration/admission contract coherent. One possible implementation is to include the configured per-peer ceiling minus framing bytes in outbound capacity checks; another is a justified minimum configuration contract. Preserve API compatibility and the two delimiter bytes in accounting. Add a regression proving that accepted reliable state can be queued for each affected recipient and that rejection preserves existing state.

## Design details worth preserving

### Server and protocol

Primary new modules are `crates/sorotte-server/src/frame_limits.rs`, `resources.rs`, `local_clock.rs`, `network/resource_tests.rs`, and `persistence_actor/shutdown.rs`. Normative contract: [SERVER_BOUNDARIES.md](/C:/Users/shaun/Documents/workspace/sorotte/tmp/v0.2.9/docs/SERVER_BOUNDARIES.md).

`sorotteLargeProtocolFramesV1` advertises the 512 KiB contract. The protocol's existing default remains 64 KiB. The allocation-bounded `message_fits_line_limit` checks serialized bytes with delimiter accounting handled at transport. CLI and GUI readers accept the large limit and advertise the capability. A shared-state change is intended to preserve complete readable snapshots for every recipient before authority commits; optional media signatures may be omitted without dropping roster members. Empty-room names use a unique compact dummy-member encoding.

Projection covers Hello, file, room, feature and playlist changes, including multiple commands in either feature/playlist wire order. It includes retained barrier participant names after disconnects and control-message headroom. Transient fanout has an aggregate budget of one quarter of the global queued-byte setting. Fallible runtime configuration setters exist alongside retained convenience APIs. Check the two missing admission cases before expanding this design.

The maximum valid audio signature fixture was moved out of the general protocol fixture inventory into `fixtures/media-match/maximum-valid-media-signature.json`; it contains 1,024 actual SAU2 anchors. A generated roster test checks compaction with 57 providers, preserving 58 visible members. CLI/GUI transport tests exercise actual server-generated Unicode and metadata snapshots larger than 64 KiB with fragmented LF/CRLF input.

Resource defaults are 1,024 active connections, 128 unauthenticated, 128 per IP, 4 MiB per peer and 64 MiB aggregate. Admission precedes queued workers; mapped IPv4 addresses share a bucket. RAII permits survive through actual writes and cleanup, and replacement periodic state adjusts reservations without reordering reliable traffic. Metrics expose current and peak resource ownership.

Ping state stores at most 64 issued challenges per connection. Wire identity remains globally distinct across reconnects and repeated wall samples; actual RTT uses local elapsed time. A challenge is accepted exactly once, with a 90-second maximum RTT/estimate age. Wall-clock timestamps remain for wire/persistence where required. OS-suspend behavior of Instant is not represented as universally suspend-inclusive.

The SQLite worker busy callback checks the shared control deadline in short intervals and between operations. Direct actor shutdown reserves join time and keeps an observable registry for workers not yet joined. Arbitrarily blocked filesystem calls are not claimed cancellable. Fix the queued-Flush gap without hiding late workers or durability failures.

Media extraction has a total 555-second operation ceiling (15-second probe plus three 180-second audio windows), 64 KiB stdout and bounded stderr with only a 16 KiB diagnostic tail, cancellation during analysis, and one-second owned cleanup. Windows uses suspended spawn/job attachment/resume. Unix pumps nonblocking pipes and process groups; fixture wrappers deliberately use `.sh` so their executable path differs from their launch marker.

Owned mpv process launch is atomic with Windows job attachment. Linux uses a process-lifetime launcher thread with PDEATHSIG; launching from a short-lived worker had incorrectly killed healthy children, and the implementation addresses that ownership seam. Exited leaders are observed without immediately permitting PID reuse during group cleanup. External players are never enrolled in the cleanup scope. IPC terminal/drop shares one total 500 ms deadline, even across many writes or a pending heartbeat.

Lua resources retain native handles/descriptors across the materialization/load seam, validate ownership and permissions, reject links/substitution, cap comparison reads to expected length plus one, and repair atomically. Explicit caller-provided root responsibility remains documented. A19 keeps sensitive Debug redaction and public/test identities while moving production state into small private owners.
