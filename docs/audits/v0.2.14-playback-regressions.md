# Playback regressions under investigation for 0.2.14

The reported environment was the latest tagged server and clients, local files
for the playlist failure, and direct Plex playback for delayed resume of an
already loaded video. Seek was not tested in the reported session.

The baseline production source is `8f1005cd327ba39be459bed6d543d73420087fa1`,
the main merge of 0.2.13. New regressions failed against that source before
the fixes were applied.

## Plex investigation

The multi-second resume delay remains unreproduced. Local HTTP/Plex-identity
fixtures and a read-only direct stream from the configured Plex server resumed
within the one-second test budget. The investigation included current readiness
protocol support, a controlled room, coordinated start, GUI and remote controls,
a half-second position difference, and 30-second pauses with release-pinned mpv.

Two actual GUI runtime owners with separate mpv processes also resolved the same
direct Plex stream through the normal source-resolution worker. Both clients
played before each pause. Alternating the initiating client across four resumes
produced eight physical resume measurements between 75 and 157 milliseconds.
This test includes both clients' actual readiness; no participant is made
artificially Playable. It is retained as the explicitly provisioned manual test
`real_mpv_two_plex_clients_resume_loaded_stream`.

A disposable Windows Sandbox also rendered the direct Plex video with `gpu-next`
while a simulated watch-sync request stayed pending. Its three resumes took
62, 86 and 87 milliseconds. Watch-history writes were disabled. The Sandbox was
stopped and its temporary private input removed. These are local reproductions,
not hosted release qualification or proof that the original delay is resolved.

The affected client and an original-session log are still needed to distinguish
the unobserved failure path. Publication of 0.2.14 remains pending.

## Regression execution

The new current-server tests run against `ServerRuntime`, the GUI runtime owner
and real mpv. Native qualification now requires all four opt-in real-mpv cases;
a missing, skipped or failed case fails that stage. Their default inputs are
local fixtures, with no Plex credentials or external media required.

Local client-core and GUI suites passed, including 1,185 GUI tests and all seven
new hermetic current-server regressions. Static preflight and all-feature,
all-target workspace Clippy and all 14 GUI semantic scenarios also passed.
Exact-source full workspace, hosted, packaged
and native release qualification still needs completion under
[the release contract](../RELEASE_QUALIFICATION.md).
